# Built-in Bluetooth

Examples that connect Sylvac Bluetooth® instruments with the **built-in Bluetooth** of a phone,
tablet or computer, without Sylvac dongle and without Sylvac library. They use the operating system's
own Bluetooth API and the [Sylvac GATT profiles](../gatt-profiles) directly.

| Folder | Platform | Content |
|---|---|---|
| [android/example](android/example) | Android 13+ | Sylvac Bluetooth Example, a Kotlin app with no dependencies (preview) |

For other platforms, see the [list of third-party Bluetooth APIs and libraries (PDF)](../docs/MAN-DeveloperResources_OS.pdf).

Native development with the built-in Bluetooth is not supported by Sylvac, see
[Support](../README.md#support).
