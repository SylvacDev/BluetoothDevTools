# Bluetooth 5 SMART dongle (BL654, BT5)

The Bluetooth 5 SMART dongle connects Sylvac Bluetooth instruments to a computer over Bluetooth 5.

- **Module:** BL654 (Ezurio, formerly Laird Connectivity)
- **Sylvac ref.:** 981-7102
- **Instrument connections:** up to 16, long range mode available
- **Computer side:** virtual serial port, `COMx` on Windows, `/dev/ttyACMx` on Linux

Use it with the [Sylvac libraries](../../libraries): they give you instruments, live values and commands without any Bluetooth programming, and the same code also runs with the Bluetooth 4 dongle.

More information on the [dongle product page](https://www.sylvac.ch/product/dongle-smart/).
